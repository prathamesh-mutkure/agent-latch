## Notes

- Amounts are USDC strings. One chain: Ethereum Sepolia.
- Demo policy: autonomous 0.2 USDC, hard limit 1, daily cap 5. A new agent starts there. 0.2 allows, 0.5 waits for approval, 2 blocks.
- `ens.name` is set when ENSjs returns an owner or the registry status is `REGISTERED`.
- Sepolia demo signer: `0x142B99367b928608835501633534411EFc467737`. Parent name: `agent-latch.eth`.
- `POST /agents/:id/ens` deploys a UserRegistry under `ENS_PARENT_NAME` when needed, then registers the agent label, points it at the signer's Permissioned Resolver, writes the signer's ETH address, and copies the current Postgres policy onto the name when that copy is not looser than the published one. The signer must be the parent owner and hold Sepolia ETH. An action is blocked when that name is missing, expired, or has no published policy. The spending decision reads the name.
- `TOKEN_TRANSFER` sends Circle USDC from the executor key to an Ethereum address. `SWAP` sells that USDC for Sepolia WETH through Uniswap SwapRouter02. Both run only after allow, or after a World approval settles, and the action is marked executed only once the transaction lands. The hash is stored on the action reasons (`usdc transfer` or `uniswap swap`). `0xvenue` is refused. `API_CALL` and `CONTRACT_CALL` stay unsigned policy decisions. Intercepta stays on `X402_PAYMENT`. Policy stays free of sponsors.
- The product name in the web app, World App copy, pushes, and the MCP server is DSAP (Delegated Spend Authorization Protocol). Package names stay `@agentlatch/*`. ENS names stay under `agent-latch.eth`. Signed agent requests still use the `x-agentlatch-*` headers. The browser session key is `dsap.session`.
- The dashboard polls the API through `/api` (Vite proxy locally, Vercel rewrite live, prefix stripped). When signed in, calls send `Authorization: Bearer <session>`. Signed out, every page except `/approve/:id` shows the QR sign-in. A 401 drops the stored session. On desktop, approvals show "Decide in World App", a `world.org/mini-app` link. Approvals expire after 5 minutes. The ENS pill stays `REGISTERED` when the name is registered. The console mark is `apps/web/public/logo.png`.
- The public API is `https://dsap-protocol.onrender.com` on Render Free, with Neon. `https://www.dsapprotocol.xyz/api` rewrites to it. A ping every 5 minutes keeps the instance awake. Sign-in nonces and QR pairing codes stay in that one process. The API stays off Vercel because that host runs Elysia as a short function. The MCP server stays stdio on the demo machine. `AGENT_KEY` is for the background agent and Claude, not for the demo.
- Inside World App, `/` redirects to `/mini`. `/mini` signs the owner in with one `walletAuth` (request ID `link`), asks for notification permission, and lists the owner's agents and pending approvals from `GET /me`. `/approve/:id` gets the challenge, signs it in World App, and posts `decide`. Deny ends the approval there. Approve returns the World ID user code and link. The owner opens World ID, checks the code, and taps Authenticate with World ID or Deny sign-in. The page follows `worldIdStatus` until the API settles it. Closing the World App prompt changes nothing.
- World ID for Agents uses `WORLD_OIDC_ISSUER`, `WORLD_CLIENT_ID`, and `WORLD_CLIENT_SECRET` on the API. A missing value makes approve 503. Device codes last 20 minutes and approvals 5, so an approval expires before its code does.
- The public Sepolia RPC rate-limits ENS reads (`Request exceeds defined limit.`). An action submit then gets 503, and approve says the ENS name could not be read. Set `SEPOLIA_RPC_URL` to a keyed endpoint for the demo.
- Pushes use `WORLD_APP_ID` and `WORLD_NOTIFICATION_API_KEY` and fire only when an action opens an approval. A missing key or an agent with no owner skips the push with a log line. A push World refuses logs its reason.
- The payments page lists `X402_PAYMENT` actions. Its target is the resource URL. The API gets the 402 quote, Intercepta screens the quote's `payTo`, then the executor key signs an EIP-3009 authorization and retries the URL with `PAYMENT-SIGNATURE`. The seller's facilitator (`/facilitator/*`, own sellers only) broadcasts it and pays Sepolia gas. A missing key, a quote that is not exactly the action's amount, a 404 from the scan, or a refused settlement refuses the payment. Live traits may omit `txsCount`.
